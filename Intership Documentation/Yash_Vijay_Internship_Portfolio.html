Overview

Overview

This project involved building an interactive analytics dashboard for a Hospital Emergency Room dataset containing over 9,200 patient records. The dashboard provides real-time insights into patient demographics, wait times, satisfaction scores, department referrals, and admission patterns — enabling hospital administrators to identify bottlenecks and improve patient care efficiency.

Methodology

1
Data Collection & Cleaning
Imported the Hospital ER CSV dataset (9,217 rows × 12 columns) into Power Query. Cleaned inconsistencies in date formats, handled missing satisfaction scores, and standardized patient race and gender categories.
2
Data Modeling
Structured the dataset with calculated columns for age groups, wait-time brackets, and admission flags. Defined relationships for cross-filtering across demographics, departments, and time periods.
3
DAX Measures & KPIs
Built calculated measures for average wait time, patient satisfaction score, admission rate percentage, and department-wise referral counts. Created KPI cards for at-a-glance performance monitoring.
4
Dashboard Design
Assembled an interactive report with slicers for gender, age group, and department. Included trend charts, bar graphs, KPI cards, and drill-down capabilities for detailed analysis.

College Sahayak — Full-Stack Application

Category
Full-Stack Development
Type
Web Application (SPA)
Duration
6 Weeks
Status
Completed & Deployed

Overview

College Sahayak is a production-grade, full-stack web application designed to serve as a centralized study resource platform for MSBTE diploma students. The application provides organized access to study materials — lab manuals, notes, assignments, question papers, micro-projects, MSBTE important questions, lecture videos, and curriculum data — categorized by branch, semester, and subject. It features secure authentication (email/password with OTP verification + Google OAuth), role-based access control, a full admin dashboard, an integrated AI chatbot powered by the Gemini API, and is deployed on Vercel (frontend) and Render (backend) for production use.

Objectives

  • Build a scalable full-stack architecture with a clean separation between React SPA client, Express API server, and Supabase (PostgreSQL) data layer.
  • Implement secure authentication with email + OTP verification via Brevo, Google OAuth via Firebase, and JWT-based session management.
  • Develop a role-based admin panel for managing users, materials, feedback, and application data in real time.
  • Integrate a Gemini-powered AI chatbot to provide in-app study assistance for students.
  • Ensure the application is fully responsive, SEO-optimized, and deployment-ready on cloud platforms.

Core Modules

  • Authentication: Email/Password login with OTP verification, Google OAuth sync, forgot/reset password flow, and protected routes.
  • Materials Hub: 10 resource categories (Notes, Lab Manuals, Assignments, etc.) with branch/semester/subject filtering and Google Drive integration.
  • Admin Panel: Centralized dashboard with user management, material CRUD, feedback review, and bulk operations.
  • AI Chatbot: Gemini API-powered conversational assistant with markdown rendering and context-aware responses.
  • MSBTE Curriculum: Complete curriculum browser with branch, semester, and subject-level navigation.

Engineering Details

Technology Stack

Front End

  • React 19 with TypeScript for building a component-based, single-page interface using Vite as the build tool.
  • React Router v7 for client-side routing with protected route guards.
  • Custom CSS3 styling with responsive design across all breakpoints.
  • Lucide React for consistent iconography throughout the UI.
  • React Helmet Async for SEO meta tags and dynamic page titles.
  • React Markdown with GFM support for AI chatbot response rendering.

Back End

  • Node.js with Express 5 REST API layer serving 5 route modules (auth, users, materials, feedback, chat).
  • JWT authentication with role-based middleware (user/admin access control).
  • Firebase Admin SDK for Google OAuth token verification.
  • bcrypt.js for secure password hashing.
  • Express Rate Limiter for API abuse prevention.

Database

  • Supabase (PostgreSQL) for persistent storage with real-time capabilities.
  • Schema: users, materials, feedback, curriculum tables with role, verification, and OTP fields.

AI & Email Services

  • Google Gemini API integration for conversational AI chatbot assistance.
  • Brevo (Sendinblue) transactional email API for OTP delivery and verification emails.
  • Firebase Authentication for Google OAuth sign-in flow.

Deployment & DevOps

  • Vercel — Frontend SPA deployment with automatic CI/CD from GitHub.
  • Render — Backend API deployment with environment variable management.
  • Git & GitHub — Version control with feature branching.
