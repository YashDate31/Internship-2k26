# 🏥 Hospital ER Data Analytics Dashboard

This repository contains a Data Analytics project focusing on Hospital Emergency Room (ER) Data. The project features a comprehensive Power BI dashboard that provides insights into ER operations, patient flow, and overall hospital performance.

## 📊 Repository Contents

- **`Hospital_Dashboard.pbix`**: The main Power BI dashboard file containing all the interactive visualizations and data models.
- **`Hospital ER_Data.csv`**: The dataset used for the analytics.
- **`HealthCare Hospital-1.png` & `HealthCareHospital-2.png`**: Preview images/screenshots of the dashboard.

## 🚀 Getting Started

1. **Prerequisites**: You will need [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/) installed on your machine to open and interact with the dashboard.
2. **Opening the Dashboard**: 
   - Clone or download this repository to your local machine.
   - Double-click on `Hospital_Dashboard.pbix` to open it in Power BI Desktop.
3. **Data Source**: The dashboard is powered by the included `Hospital ER_Data.csv`. If Power BI prompts you to update the data source path upon opening, you can point it to the local CSV file in this repository.
