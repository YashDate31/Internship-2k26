# Day 15 - GitHub Sync & Figma Design Plugins

## 1. GitHub Repository Maintenance Commands
```bash
# Check current repository status
git status

# Add modified website files
git add .

# Commit changes with descriptive summary
git commit -m "Updated website navigation and applied design feedback"

# Push to main GitHub repository
git push origin main
```

## 2. Useful Figma Plugins Explored
- **Unsplash**: Instant insertion of high-resolution royalty-free imagery into UI shapes.
- **Iconify**: Search and import thousands of SVG icons directly into design artboards.
- **Autoflow**: Automatically draw user flow connectors between screen wireframes.
- **Stark**: Accessibility checker for contrast ratios and color-blind friendliness.
