Mouse Events Syntax

  • click: Fires when a pointing device button is pressed and released.
  • dblclick: Fires when a pointing device button is clicked twice rapidly.
  • mousedown: Fires when a pointing device button is pressed.
  • mouseup: Fires when a pointing device button is released.
  • mousemove: Fires when a pointing device is moved.
  • mouseover: Fires when a pointing device is moved onto the element.
  • mouseout: Fires when a pointing device is moved off the element.

Example:

        document.getElementById('myButton').addEventListener('click', function(event) {
            console.log('Button clicked!');
        });
